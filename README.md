# Statistical Modeling Project

A statistical analysis project using hypothesis testing, regression modeling,
and data visualization to examine relationships between economic and
educational indicators.

## Project Overview

This project applies statistical methods to analyze data, identify
relationships between variables, and evaluate statistical significance.

## Methods Used

- Descriptive statistics
- Hypothesis testing
- T-tests
- ANOVA
- Regression analysis
- Data visualization

## Technologies

- R
- Microsoft Excel
- Statistical Modeling
- Data Analysis

## Repository Contents

- `project.R` – R code used for the statistical analysis
- `r_script.R` – Additional R analysis
- `Project_report.pdf` – Final project report
- `Gini_coefficient.xlsx` – Gini coefficient data
- `education_data.xlsx` – Education data
- `education_gini_regression.xlsx` – Education and Gini regression results
- `income_gini_regression.xlsx` – Income and Gini regression results
- `summary_stats.xlsx` – Summary statistics
- `full_analysis_output.txt` – Statistical analysis output
- `Figures.zip` – Project visualizations

## Key Skills Demonstrated

R Programming • Regression Analysis • Hypothesis Testing •
Statistical Analysis • Data Visualization • Data Interpretation
